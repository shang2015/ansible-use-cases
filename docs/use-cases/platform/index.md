# Automation Platform

Use cases for installing, configuring, migrating, protecting and operating Ansible Automation Platform itself: the platform gateway, automation controller, automation hub, Event-Driven Ansible controller, execution environments and automation mesh. Most are delivered with the containerized installer on RHEL or the operator on OpenShift and managed as code from Git.
