# AWS

Provision, protect and operate Amazon Web Services environments with `amazon.aws` modules and the validated `cloud.aws_ops` and `cloud.aws_troubleshooting` collections. The use cases cover networking and compute, web applications, backup, patching, connectivity diagnosis, security posture, inventory, CloudFormation and VM migration.
