# Event-Driven & Observability

Event-Driven Ansible listens to events from monitoring, observability, messaging and webhook sources, and starts the matching automation when a rule fires. The use cases start with the general self-healing pattern, and the vendor pages for Dynatrace, Splunk ITSI, SCOM, Instana, LogicMonitor Edwin AI, Zabbix, Turbonomic and BigPanda show how each observability tool connects.
