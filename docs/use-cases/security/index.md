# Security

Use Ansible Automation Platform to harden and scan systems, remediate vulnerabilities, manage firewall and threat-prevention policy, orchestrate SIEM and EDR tools, and handle secrets, identity and certificates. Most pages combine Red Hat content such as RHEL system roles and Red Hat IdM with certified collections from security vendors, and can be triggered by Event-Driven Ansible. For the support level and freshness of each vendor's content, see the [vendor pages](../../vendors/index.md).
