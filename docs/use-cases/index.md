# Use cases by domain

Each domain has its own page with:

- **Solution use cases**: outcome-level scenarios, each as one table (*Description · Collection · Key content · Notes*).
- **Product use cases**: the modules of each collection in the domain, grouped by outcome.
- **Collections in this domain**: support level, provider, version and last update.
- A **PDF** of the whole domain in the same format, also on the [Downloads](../downloads/index.md) page.
