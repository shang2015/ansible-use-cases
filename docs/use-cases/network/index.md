# Network

Automate the full lifecycle of multi-vendor networks: back up and restore configuration, detect drift, enforce standards and validate operational state. Extend the same approach to upgrades, zero-touch provisioning, DDI, load balancers, data center fabrics, VPNs and telemetry-driven response. Validated network collections provide platform-independent roles; vendor collections supply the device and controller modules.
